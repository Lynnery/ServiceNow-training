>>

>> 
>> If the group name contains more than 4 chars then make a new incident to hardware staff and the name of the guy that ordered the phone.
>> 
>> If the user selected the color to be black then the memory automatically changes to 64.

>
>> The workflow requires approval from Yarin Elias (if the user doesn't exist, create the user).
>>
>> If the request is approved by Yarin, create a script to run precisely 10 minutes after the approval and log `'Hello World!'`. Otherwise, take no action.
>>
